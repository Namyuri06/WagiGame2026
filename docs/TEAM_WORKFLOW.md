# 팀 협업 및 코드 규칙

## 역할 분담

- **파트 1 · 플레이어/성장 (박지윤):** 2D 사이드뷰 횡스크롤 이동·애니메이션, 음식 획득, 플레이어 성장과 공통 인원 수 데이터 관리
- **파트 2 · 군단/AI (남유리):** 동료 비둘기 추적·군단 관리, 일반 인간 잡몹의 이동·공격 패턴, 인간 포섭과 상납 상태 관리
- **파트 3 · 전투/레벨 (진자연):** 눈빛 공격·응가 폭격의 피해 처리와 인원 비례 강화, 일반 잡몹 전투 규칙, 보스전 없는 스테이지와 잡몹 웨이브 설계
- **파트 4 · UI/통합 (이우진):** 체력·인원 카운터·스킬 상태 HUD, 사운드·이펙트 매니저, 파트 간 UI 연결. 미니맵은 구현하지 않습니다.

각 파트는 위 표의 코드·에셋 영역을 우선 소유합니다. 공용 코드, 공용 데이터 형식, 다른 파트의 프리팹을 변경해야 할 때는 먼저 담당자와 인터페이스를 합의하고 변경점을 공유합니다.

## 팀원 브랜치와 세션 협업

각 팀원은 본인 이름을 사용한 장기 브랜치를 직접 만듭니다(예: `team/<이름>`). 팀원 브랜치는 프로젝트 완료 전까지 유지하며, `main`에 병합한 뒤에도 삭제하지 않습니다. `main`에 직접 커밋하지 말고 본인 브랜치에서 개발합니다.

`main`으로 보내는 Pull Request는 동아리 세션 시간의 팀 회의에서 함께 엽니다. 회의에서 변경 내용과 충돌 여부를 검토하고 PR을 병합합니다. 세션 전에는 완료된 작업도 각자 브랜치에 보관하고, 회의 전에는 `main` PR을 열거나 병합하지 않습니다. 병합 후 최신 `main`을 각자 브랜치에 반영하고, 팀원 브랜치는 프로젝트 완료 때까지 유지합니다.

## 공통 데이터 이름

기획 단계에서 정한 핵심 값은 아래 이름을 유지합니다.

| 의미 | 식별자 | 형식 |
| --- | --- | --- |
| 플레이어 체력 | `playerHp` | `float` |
| 동료 비둘기 수 (응가 폭격 강화 기준) | `minionCount` | `int` |
| 포섭한 인간 수 (눈빛 공격 강화 기준) | `bribedHumanCount` | `int` |
| 눈빛 공격 대기 시간 | `eyeAttackCooldown` | `float` |
| 눈빛 공격 피해량 | `eyeAttackDamage` | `float` |
| 응가 폭격 피해량 | `poopBombDamage` | `float` |

눈빛 공격 피해량은 `bribedHumanCount`에, 응가 폭격 피해량은 `minionCount`에 비례해 증가하도록 합니다. 인원당 증가 계수와 최대 피해량은 공용 밸런스 데이터에서 조정하며, 구체적인 수치는 플레이 테스트 뒤 합의합니다.

새 시스템은 소유 파트와 공개 인터페이스를 정하고, 다른 파트가 내부 구현에 직접 의존하지 않도록 합니다. 음식 정보, 일반 잡몹·스테이지 스펙과 밸런스 값은 `Assets/_Project/Data/`의 ScriptableObject로 관리합니다.

## UI 갱신과 이벤트

게임 상태를 바꾸는 시스템은 상태 변경 시점에 C# `Action` 이벤트를 발생시킵니다. UI는 필요한 이벤트를 구독해 체력, 동료 비둘기 수, 포섭 인간 수와 스킬 상태를 갱신하고, 파괴되거나 비활성화될 때 구독을 해제합니다. 미니맵은 범위에 포함하지 않습니다. UI가 플레이어·적 스크립트의 내부 변수를 매 프레임 직접 읽는 방식은 피합니다.

## 코드와 에셋

- C# 타입과 메서드는 `PascalCase`, 로컬 변수와 매개변수는 `camelCase`를 사용합니다. 공통 기획 식별자는 위 표를 우선합니다.
- 파일 하나당 주요 `MonoBehaviour` 또는 데이터 타입 하나를 두고 파일명과 타입명을 맞춥니다.
- 스크립트는 `Assets/_Project/Scripts/`의 기능별 폴더에, 공유 가능한 밸런스 데이터는 `Data/`에 둡니다.
- Unity가 만든 `.meta` 파일을 원본 에셋과 함께 커밋합니다. 에셋 이동은 파일 시스템에서 직접 이동하지 말고 Unity 에디터에서 합니다.
- Pull Request는 작고 한 목적에 집중하게 만들며, 세션 회의에서 병합 전 충돌과 Unity Console 오류를 확인합니다.
